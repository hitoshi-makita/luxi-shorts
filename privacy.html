概要利用規約

前提

luxi-shorts は、運営者が自分の TikTok アカウントに自分の動画を投稿するためだけの個人用ツールです。運営者本人のパソコン上でのみ動作し、サーバーを持ちません。運営者以外の利用者はいません。

扱う情報と保存先

情報使いみち保存先
アクセストークン
リフレッシュトークン		 投稿を実行するため 運営者のパソコン内のファイル1つ
（config/tiktok_token.json）
アカウント名
選べる公開範囲
動画の長さの上限		 投稿前の確認と、規定に反する投稿を止めるため 保存しない（実行中のみ画面に表示）
投稿した動画のID・投稿日時 投稿記録として残すため 運営者のパソコン内のファイル
（tiktok.json）

やらないこと

  • 取得した情報を第三者に提供・販売・共有しません。
  • 外部のサーバーやクラウドに送信しません（TikTok の API を除く）。
  • 広告配信、行動追跡、プロファイリングには使いません。
  • 他の TikTok 利用者の情報は取得しません。

保存期間と削除

トークンは、運営者が TikTok の設定画面から本アプリの連携を解除するか、パソコン上のファイルを削除した時点で無効になります。リフレッシュトークンは TikTok の仕様により発行から365日で失効します。

連携の解除は、TikTok アプリの「設定とプライバシー → セキュリティ → アプリの管理」からいつでも行えます。

問い合わせ

本ポリシーに関する問い合わせ先は、TikTok 開発者ポータルに登録された運営者の連絡先メールアドレスです。内容は予告なく変更されることがあります。
